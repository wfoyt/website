# Foyt Labs

A buildless personal project showcase for the public repositories of [wfoyt](https://github.com/wfoyt). Original ASCII branding, an animated orbital sculpture, three terminal color themes, project filters, detail dialogs, and keyboard navigation.

Serve `dist/` with any static web server. No build or package installation is required.

## Content

The four listed repositories were explicitly verified public using GitHub metadata on October 31, 2026. Content is a curated snapshot, not an authenticated GitHub integration. To add projects, verify public visibility first and update the directory and its counts. Never embed credentials or private repository metadata.

Keyboard: Cmd/Ctrl+K opens the command menu; P jumps to projects; A opens the lab section; T cycles themes; M toggles motion; Escape closes dialogs. Respects reduced-motion preferences.

Original logo assets live at `dist/logo.svg` and `dist/foyt-labs-ascii.txt`. Visual direction inspired by Omarchy, with an original Foyt Labs identity.
